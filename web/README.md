# 《盲域》阅读站

阅读站使用 Node.js 18 或更新版本，在运行中直接读取 `正文` 下的章稿和[档案室](../正文/档案室/README.md)。阅读进度保存在浏览器里。

## 启动

Windows 双击 `start.bat`，也可以在项目根目录运行下列命令。

```powershell
.\web\start.bat
```

macOS、Linux 或 Git Bash 在项目根目录运行下列命令。

```sh
sh web/start.sh
```

打开 [本地阅读站](http://127.0.0.1:4317/)，按 `Ctrl+C` 停止。需要换端口时，可以在启动命令末尾加端口号，比如 `sh web/start.sh 4318`。同一浏览器使用原地址可以接续原有进度。

## 更新正文

1. 把章稿保存到 `正文` 下对应的卷目录，例如 `正文/第一卷/第002章.md`。文件以一级标题开头，各段之间留空行。目录按卷号和章号排列，支持阿拉伯数字及常用中文数字。
2. 阅读站会自动发现新章，未登记的章稿显示为「草稿」。在[正文索引](../正文/README.md)中登记后，阅读站读取对应的当前稿和状态。修订时保留卷号、章号，读者可以在同一章节接续。
3. 旧稿归入对应卷的 `历史稿`。要从站内撤下章节，可将当前稿移入 `历史稿` 并更新索引。

打开的网页大约每两秒检查目录及正在阅读的内容。新增或修改章稿、修改状态和更新档案都会在原页面生效。升级阅读站代码后，已经运行的旧版服务需要重启一次。

## 维护档案室

每个条目在 `正文/档案室` 存为一个 Markdown 文件。正文蓝标、悬浮摘要、档案室、搜索和设定集按公开章节显示，保存档案后自动更新。新增记录时，使用条目格式登记公开章节。[档案格式与维护规则](../正文/档案室/README.md)

滚动到章末或翻到最后一页会记为读完。遇到一屏容纳整章的情况，可用「标记本章已读」。档案室默认开放连续读完的章节，从正文词条进入时还会以当前章为上限。想查后续内容，可以选择「查看后续内容」，在剧透提示里确认。返回阅读时恢复按进度查看。
