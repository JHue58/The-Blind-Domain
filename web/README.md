# 《盲域》阅读站

阅读站使用 Node.js 18 或更新版本，启动时直接读取项目里的 Markdown。`web` 管理读者端页面、公开资料目录和封面。正文仍按[正文索引](../正文/README.md)登记，服务只读取这些文件，阅读进度保存在浏览器里。

## 启动

Windows 双击 `start.bat`，也可以在项目根目录运行下列命令。

```powershell
.\web\start.bat
```

macOS、Linux 或 Git Bash 在项目根目录运行下列命令。

```sh
sh web/start.sh
```

打开 [本地阅读站](http://127.0.0.1:4317/)，按 `Ctrl+C` 停止。需要换端口时，可以在启动命令末尾加端口号，比如 `sh web/start.sh 4318`。同一浏览器使用原地址可以接续原有进度。

## 发布正文

1. 章稿按创作流程保存到 `正文` 下的卷目录。文件以一级标题开头，各段之间留空行。支持常用的加粗、斜体、分隔线、引用、列表和管道表格。
2. 在[正文索引](../正文/README.md)的章稿表更新卷次、章号、标题和当前稿链接。章号和卷次支持数字及常用中文数字，章节按索引顺序排列。
3. 章节达到定稿后，将状态记为 `定稿`。阅读站以本表的当前定稿链接为发布依据，撤下章节时先更新状态，再替换正文文件。修订时保留卷号、章号，读者可以在同一章节接续。

打开的网页大约每两秒检查目录及正在阅读的内容。新增定稿、修订正文及更新下列公开资料时，浏览器会自动读取改动。

## 发布设定、档案和术语

`content/catalog.json` 是读者站使用的公开目录。`settings` 登记已定的设定，`archives` 登记已确认、可供读者查阅的档案。每个条目使用唯一的小写字母、数字和短横线组成的 `id`，填写 `title`、`summary`、`category`，正文保存为 `content/entries/<id>.md`。页面标题来自目录，正文可直接以一段文字或二级标题开始。

- 档案的 `category` 使用 `character`（人物）、`zone`（域区）、`phenomenon`（域闻）或 `other`（其他）。有档案编号时可填 `code`，编号会显示并可检索。
- `terms` 登记可公开的设定名词、人物名或其他专有名词。`name` 是正文匹配的写法，`definition` 是预览释义。填写 `entry` 可以跳到已入目录的设定或档案，填写 `section` 可以定位到该页同名小标题。别名作为另一条术语登记。
- 公开资料页可用 `[文字](#/settings/条目ID)`、`[文字](#/archives/条目ID)` 或术语链接相互引用。条目摘录应先依据已确认设定和正式档案核对。

首批六篇设定依据 v1.0 的已确认核心、当前世界规则及作者通过的第 1 至 4 题整理。档案馆目前为空，待人物、域区或域闻有正式记录后入库。[设定审核](../设定审核.md) · [世界规则索引](../资料库/世界规则.md) · [v1.0 世界观总览](../盲域_世界观设定集_v1.0/00_世界观总览.md)
