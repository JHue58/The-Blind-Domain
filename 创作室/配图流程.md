# 《盲域》配图流程

每章在场景卡里评估插图。优先选有城市生活痕迹、真实光源和空间层次的地方，取读者此刻已经遇见的反常或现场。声音、视野之外的事或尚未核实的证词可以在正文配图里留白。读者只看正文也应能明白发生了什么。

## 档案配图

- 具体域闻、域区、域体等异常条目，首次向读者开放时至少随附一张直接对应的已审图。已有正文插图确实能说明该条目时，可以沿用。已建档的具体异常线索也用同一标准检查，文字仍按证据写明现象的归属是否已知。[档案室](../正文/档案室/README.md)
- 写声音、事件或仅有片段目击的异常时，从正文出现过的现场、载体或可见痕迹取景。图注写明「场景示意」或「据目击描述绘制」。故事中确有其物的证物也按实际出现的状态绘制，图注注明绘制依据。形态、范围和成因依照公开章稿所能支持的内容。
- 策划时同时确定档案首次公开章和对应图。图和条目同轮审核，核对 `chapter`、`anchor` 和 `archives`。待配图的新异常条目先留在[调查底稿](../资料库/域区与域闻.md)，配齐后再入读者档案室。

## 选图与审图

1. **定画面。** 在章纲记录正文版本、视角、具体时刻、插入段落、可见事实和悬而未决的信息。优先从当事人视点选环境。人物需要入镜时，留背影、难以辨认的远景或局部。仅供档案使用的图也登记来源段落。
2. **取参考。** 打开[视觉设定](../资料库/视觉设定/README.md)。取当前画风及相关地点、人物的有版本参考原图作为输入，标明每张参考图的用途。有人入镜时核对服装、伤势、持物和站位。影响身份、解谜或跨章设定的新增外观提交[设定审核](../设定审核.md)。
3. **生成和记录。** 在视觉设定的对应卷保存提示词、输入图的版本、正文出处和审图结果。保留需要接着修的候选图时，放在视觉设定目录的 `草案/` 下。公开用图以 JPG、PNG 或 WebP 导出，使用带版本后缀的小写文件名。新画面重新生图和审图，再登记新版本。
4. **主编审图。** 核对现场视角、光源、通路与门窗状态，道具归属、人物服装及伤势侧别。检查人物与反光里有无正脸，逐一核对容易被读者当作线索的文字、地标、影子和裁切。拟供档案使用时核对图片、图注和替代文本是否只表达该时点的已知信息。误导读者的画面先重做或退回草案。
5. **上架和交接。** 登记审过的图，验证正文的插入位置、滚动与翻页，核对档案未解锁时图不显示、首次解锁时对应图可见。修订章稿后复核相关图、人物参考和档案。更换或撤回错误的图时，核对条目在读者首次打开时仍有合格的对应图。无法同步修好时，将受影响的具体异常档案退回调查底稿，记录待补图及复核位置。[创作进度](../创作进度.md)

## 阅读站的插图索引

把审过的文件放在 `正文/插图/发布`，在[插图索引](../正文/插图/索引.json)以文件主名登记。章稿按原样写作，索引指定正文插入位置和档案用途。保存后，已打开的阅读站会重新读取。

| 字段 | 填法 |
| --- | --- |
| `status` | 主编审过并可展示时填 `approved`。候选图填 `draft`，撤图改为 `withdrawn`。审核指当前图与当前章稿相符，章稿状态在正文索引登记。 |
| `file`、`sha256` | 填发布目录中的文件名和最终导出文件的 SHA-256。文件名沿用条目键，例如 `chen-ning-v1.jpg`。macOS 可执行 `shasum -a 256` 并追加图片路径，Windows 可用 `Get-FileHash` 取值后转小写。 |
| `width`、`height` | 最终图片的实际像素尺寸。用于移动端和翻页时预留空间。 |
| `alt`、`caption` | `alt` 描述可见信息，`caption` 标明图的性质和场景或人物。两者都按公开时点写。 |
| `chapter`、`anchor` | 来源章的站内编号，如 `v1-c002`。将揭示画面内容的一整个叙事段落或对话段落抄入 `anchor`，与现行章稿对应。同段文字在该章应唯一。 |
| `inline` | 填 `true` 时在来源章的 `anchor` 段后显示。仅用于档案时可省略。 |
| `archives` | 对应档案使用此对象。键用档案文件主名，值用图片关联最早公开的章号或 `spoiler`，如 `{"huai-du-station-broadcast": "v1-c001"}`。图片在来源章和关联时点都满足时显示。首次公开用图选该章或此前已经出现的来源段落。 |

图片、校验值或对应段落失配时，阅读站隐藏该图，正文和档案文字继续可读。替换时用新版本的文件和索引项，核对每个引用后撤回旧项。移除误图时先把对应项标为 `withdrawn`，它会同时从小说正文和档案室撤下。
