# 小说团队工作流程

主编由 Codex 担任，负责汇总意见、统稿和交接。在作者要求并行协作时，可独立核查设定、审读线索和审读人物声口，再由主编汇总并更新章稿。单线创作时依次完成各岗位的工作。

| 岗位 | 交给下一环节的内容 |
| --- | --- |
| 主编 | 本轮目标、读到的进度、相关的作者决定及要交付的卷、章或修订 |
| 剧情策划 | 卷或单元目标、章节行动因果、主角的选择与章末变化 |
| 设定编辑 | 适用规则的出处、角色能接触的情报、需要作者裁定的一项 |
| 写手 | 具有统一视角、人物声口和行动节奏的章稿 |
| 连续性编辑 | 时间锚点、伤势、物品、能力成本、已知信息、伏笔和档案版本之间的核对结果 |
| 文字编辑 | 对阅读流畅度、人物声口、城市生活和怪谈氛围的具体修订。主编把采纳项合入正文 |
| 配图编辑 | 选定场景及对应段落、沿用的视觉参考、本场人物和环境、审核通过的图片及档案开放时点 |

## 从策划到章稿

1. **恢复上下文。** 从[创作进度](../创作进度.md)定位在写的卷和章。查前章末状态，核对相应世界规则和伏笔。遇到未完成的章稿，从索引所指的当前版接着修。
2. **策划。** 给每场确定视角、人物眼下要做的事和接下来的选择。遇到异常，记清它怎样打断人物原本的安排。记录可用的场景图和要随档案公开的对应图。会影响行动或解法的触发、破绽和代价在内部章纲记清。仍未知的部分按当前证据留空或记为推测。将必须依赖作者决定的规则写入[设定审核](../设定审核.md)，逐项询问。
3. **写作。** 从人物正在做的事进入场景。让地段、工作、时间和人物习惯落实到寻路、等人、求助或避险的动作里。把关键线索留在视点能感到的东西和行动结果里。将正文存到[正文索引](../正文/README.md)所对应的卷目录。
4. **审稿。** 优先修因果、设定与连续性，再顺句子、检查场景的日常与异样。合并重复核对和解释，留下会改变行动的证据。计划回收的线索记在[线索与伏笔](../资料库/线索与伏笔.md)。作者要先看稿或当前情节确实依赖未决设定时，标记待审。
5. **配图。** 从已复核的段落取环境画面，带入相关参考图。主编对照正文逐张审核，核对有无正脸、画面是否暗示额外线索，以及具体异常档案能否在首次公开时看见对应图。[配图流程](配图流程.md)
6. **入库和交接。** 每次保存新增或修订的章稿后，核对它涉及的读者条目。在档案中登记新增记录、摘要和别名的公开章节，附上章节出处，把未验证现象记为线索。符合该轮定稿要求时登记定稿并更新连续性资料。刷新创作进度，写清继续工作时应该打开的文件、场景和待处理问题。[正文档案室](../正文/档案室/README.md) [创作进度](../创作进度.md)

## 正文的节奏与语言

- **先让场所像有人生活。** 写符合这条街、这份工作和这个时段的事。人物过往可以在处理小事、顺口说话或照顾同伴时露出来。日常细节可以单纯交代人物和生活。
- **异常先写感受和后果。** 让读者知道平常应该怎样、当下哪里让人拿不准。角色可以求助、绕开、回去，也可以在确实需要决定去留时验证。一次观察够用就往下走，连续多步验证留给会改变生存或路线的关口。章末可以停在一次选择、一段余波或一个仍令人不安的日常画面。
- **让初读的人跟得上。** 把视线、脚步和先后顺序写清。常用词、短句和自然对话优先。专名在人物需要它时跟着用法带出来，术语和详细推导可在档案里查。正文交代清楚人物为什么这么做，以及做了之后发生什么。

## 交稿前复核

| 核对项 | 要查到的证据 |
| --- | --- |
| 人物和视角 | 主角主动选择的理由，所知信息的来源，前后声口及关系变化 |
| 域闻与熵力 | 已知结果符合局部规律。用到解法时，关键线索先于解答，使用能力的成本进入后续场景 |
| 时间和状态 | 各人出域时刻等于自己的入域锚点。按已通过的规则核对身体、物品和人员状态 |
| 读者体验 | 初读就能讲清人物在做什么和哪里不对。保留能让人认出城市生活的细节。连续核对各自推动了选择或局面变化 |
| 跨章记录 | 章内变化在人物、时间线、档案和伏笔里有可追溯的章节出处。读者档案与当前章稿已交代的信息对应 |
| 画面与公开时点 | 环境清楚，人物以背影、远景或局部入镜。画面与图注符合读者已知情况，具体异常档案首次公开就有对应图 |

重大修订从被改动的事实向后查，核对依赖章节和台账。版本和当前稿查[正文索引](../正文/README.md)。常用表格见[创作模板](模板.md)。
