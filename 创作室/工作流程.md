# 小说团队工作流程

主编由 Codex 担任，负责汇总意见、统稿和交接。在作者要求并行协作时，可独立核查设定、审读线索和审读人物声口，再由主编汇总并更新章稿。单线创作时依次完成各岗位的工作。

| 岗位 | 交给下一环节的内容 |
| --- | --- |
| 主编 | 本轮目标、读到的进度、相关的作者决定及要交付的卷、章或修订 |
| 剧情策划 | 卷或单元目标、章节行动因果、主角的选择与章末变化 |
| 设定编辑 | 适用规则的出处、角色能接触的情报、需要作者裁定的一项 |
| 写手 | 具有统一视角、人物声口和行动节奏的章稿 |
| 连续性编辑 | 时间锚点、伤势、物品、能力成本、已知信息、伏笔和档案版本之间的核对结果 |
| 文字编辑 | 对节奏、语气、视角和恐怖感的具体修订。主编把采纳项合入正文 |

## 从策划到章稿

1. **恢复上下文。** 从[创作进度](../创作进度.md)定位在写的卷和章。查前章末状态，核对相应世界规则和伏笔。遇到未完成的章稿，从索引所指的当前版接着修。
2. **策划。** 给每场确定视角、目的、障碍、选择和结束状态。域闻的触发、破绽和代价在内部章纲备齐。将必须依赖作者决定的规则写入[设定审核](../设定审核.md)，逐项询问。
3. **写作。** 从人物正在做的事进入场景。把线索落在场景观察、对话与行动结果里，安排角色根据已获得的证据改变做法。将正文存到[正文索引](../正文/README.md)所对应的卷目录。
4. **审稿。** 优先修因果、设定与连续性，再修语言。保留仍有意悬置的谜团，在[线索与伏笔](../资料库/线索与伏笔.md)记好将来能用的证据。作者要先看稿或当前情节确实依赖未决设定时，标记待审。
5. **入库和交接。** 每次保存新增或修订的章稿后，核对它涉及的读者条目。在[正文档案室](../正文/档案室/README.md)新增或更新档案，附上章节出处，把未验证现象记为线索。符合该轮定稿要求时登记定稿并更新连续性资料。刷新[创作进度](../创作进度.md)，写清继续工作时应该打开的文件、场景和待处理问题。

## 交稿前复核

| 核对项 | 要查到的证据 |
| --- | --- |
| 人物和视角 | 主角主动选择的理由，所知信息的来源，前后声口及关系变化 |
| 域闻与熵力 | 现象触发与解法一致，关键线索先于解答，使用能力的成本进入后续场景 |
| 时间和状态 | 各人出域时刻等于自己的入域锚点。按已通过的规则核对身体、物品和人员状态 |
| 读者体验 | 可指出的日常偏差、逐步增加的压力，以及与本章行动相连的章末悬念 |
| 跨章记录 | 章内变化在人物、时间线、档案和伏笔里有可追溯的章节出处。读者档案与当前章稿已交代的信息对应 |

重大修订从被改动的事实向后查，核对依赖章节和台账。版本和当前稿查[正文索引](../正文/README.md)。常用表格见[创作模板](模板.md)。
