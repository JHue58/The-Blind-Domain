# 09｜档案体系与调查规范

## 1. 档案的作用

档案不是全知视角，而是人类在信息不完整的情况下建立的临时认知。

一份档案可以有错误、缺页、过期信息和互相矛盾的证词。档案的可信度必须和内容本身分开记录。

## 2. 域闻档案标准字段

  字段         说明
  ------------ ----------------------------------------
  档案编号     唯一编号
  名称         官方名称、俗称或暂定名称
  主要类型     五种域闻类型之一
  次要特征     其他类型表现
  危险评估     未知、无害、诡异、高危、极危、死亡
  记录状态     未记录、部分记录、已记录、已验证、失效
  首次发现     时间、地点、发现方式
  所属域区     已知域区编号
  表现摘要     最容易识别的异常特征
  已验证规则   有证据支持的规则
  未验证推测   尚未复现的判断
  触发条件     已知触发方式
  规避方式     已验证的生存建议
  生还记录     进入人数、返回人数、失联人数
  遗痕记录     是否因死亡或事件发生变化
  熵力交互     已知能力与其交互情况
  最近更新     档案最后修订时间
  证据等级     证词、影像、重复验证等

## 3. 证据等级建议

-   **E0｜传闻**：只有口述或网络传闻，来源无法核实。
-   **E1｜单次目击**：有明确目击者，但无法重复。
-   **E2｜多源记录**：存在多个相互独立的证词或记录。
-   **E3｜重复观察**：相同现象在多次调查中出现。
-   **E4｜受控验证**：在可控条件下重复验证关键规则。

E4不代表绝对真理，只代表当前证据较强。

## 4. 规则记录格式

每条规则建议分为： - **规则编号**：便于引用。 -
**规则内容**：尽量用一句话描述。 -
**证据来源**：谁、何时、如何观察到。 - **验证次数**：是否重复出现。 -
**可信度**：当前判断。 - **例外情况**：与规则冲突的记录。 -
**版本状态**：有效、存疑、失效。

## 5. 档案更新机制

当域闻发生变化时，不应直接覆盖旧档案。

建议保留： - 旧规则。 - 失效时间。 - 触发变化的事件。 - 新规则。 -
变化前后的生还记录。 - 是否与遗痕有关。

这样读者可以看到"曾经正确的规则如何变成死亡陷阱"。

## 6. 进入前调查规范（建议）

1.  确认入口和返回路线。
2.  记录现实时间锚点。
3.  检查通讯、照明、医疗和记录设备。
4.  明确队伍分工与撤退信号。
5.  复核档案版本和情报来源。
6.  不把未经验证的传闻当作生存规则。
7.  对信息型域闻采取额外防护。

## 7. 入域后调查规范（建议）

-   先观察，再触碰。
-   先记录，再尝试触发。
-   尽量一次只改变一个变量。
-   不随意分队。
-   记录时间、方向、路线和环境变化。
-   对所有新出现的规则保留不确定性。
-   发现旧规则失效时，立即标记并停止沿用。
-   任何撤退决定都应优先考虑人员生存。

## 8. 信息型域闻的档案风险

档案可能成为异常传播媒介。因此可以设置： - 分级阅读权限。 -
关键内容拆分保存。 - 对异常图像、音频和文本进行隔离。 -
记录"阅读档案是否触发异常"。 - 禁止未经审核的原始材料在普通网络传播。

这不是为了制造无意义的保密，而是因为"知道某件事"本身可能成为触发条件。
