# 《盲域》世界观设定集 v1.0

> 现代都市 · 怪谈 · 灵异 · 规则探索 · 能力智斗

本设定集整理了目前讨论形成的《盲域》世界观底稿。它不是封闭的百科全书，而是一份可持续修改的创作文档：核心设定尽量稳定，未决定的部分保留空间。

## 设定状态标记

-   **【已确认】**：创作者已经明确选择的方向。
-   **【建议设定】**：为了让世界观更容易运行而提出的补充方案，可修改。
-   **【待审核】**：涉及作品长期走向，暂不替创作者做决定。
-   **【示例】**：用于展示设定如何落地，不代表必须写入正史。

## 阅读顺序

1.  `00_世界观总览.md`：快速理解整个世界。
2.  `01_盲域.md`：盲域是什么，如何进入，时间如何运行。
3.  `02_域闻.md`：异常现象的类型、危险等级和规则。
4.  `03_熵力.md`：人类在盲域中产生的适应性能力。
5.  `04_域区.md`：盲域中的区域、连接关系与生态。
6.  `05_死亡与遗痕.md`：死亡如何改变盲域。
7.  `06_机关与试炼.md`：机械机关、规则陷阱与道德困境。
8.  `07_现实污染与域漏.md`：盲域与现实之间的相互影响。
9.  `08_组织与势力.md`：官方、民间及其他势力。
10. `09_档案体系与调查规范.md`：调查、记录与情报可信度。
11. `10_示例域闻档案.md`：可直接改写为小说章节的案例。
12. `11_世界观术语表.md`：统一用词。
13. `12_创作准则与待确认事项.md`：创作约束和仍需决定的问题。

## 本版最重要的创作方向

-   盲域是一种无法被完整定义的异常状态，而不是已经确认存在的平行宇宙。
-   域闻遵循规则，但规则可能隐蔽、复杂、被误读，甚至在特定条件下发生变化。
-   熵力是人类在盲域中为了生存而产生的适应性变化，不采用绝对强弱排名。
-   人类在盲域中使用熵力不会产生现实污染；在现实中使用则可能造成污染。
-   人在盲域中的死亡可能改变所在域区，但不同域区的反应并不统一。
-   机关和试炼可以存在，但它们不必全部是域闻，也不必全部来自盲域。
-   盲域的规模、边界和结构没有统一答案，任何地图都只是阶段性的调查成果。

## 使用说明

建议把本目录视为小说项目的"世界观底稿"。新增设定时，先判断它属于哪份文档，再记录它是已验证事实、研究推测还是民间传闻。若新设定与旧档案冲突，不要急着删除旧内容：冲突本身也可能成为剧情线索。
