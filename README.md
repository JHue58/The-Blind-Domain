## 怎么接力

1. **作者定方向。** 有会影响当前剧情的设定缺口时，Codex 每次提一个问题，附选项和对剧情的影响。你可以选择、修改答案、延期，或把该项交给 Codex。答复会写入[设定审核](设定审核.md)。
2. **Codex 统筹写作。** 从策划拟定人物选择和场景，到写手成稿，再由编辑复核规则、视角和连续性。正文按卷存放，章稿状态集中记在[正文索引](正文/README.md)。
3. **写完留下可接续的进度。** 人物状态、时间线和伏笔随定稿推进。每轮结束时，更新[创作进度](创作进度.md)，让下一次接着同一版设定和正文工作。

设定集 v1.0 是创作底稿。已通过的新增或修订设定以[设定审核](设定审核.md)为准，故事中已经发生的事件以定稿为准。策划提案和示例作为创作素材使用。
