# 《盲域》长篇小说项目

一部以都市怪谈、超自然异常和世界观构建为核心的长篇小说。人物从习以为常的城市生活里遇见异常，盲域的面貌随一次次亲历逐渐展开。

每次打开这个文件夹，从[创作进度](创作进度.md)接续。它记录写到哪里、已定的方向、最近一章和接下来要推进的事。你可以直接对 Codex 说「按项目进度继续」，也可以指定一卷、一章或一项设定。

## 怎么接力

1. **作者定方向。** 有会影响当前剧情的设定缺口时，Codex 每次提一个问题，附选项和对剧情的影响。你可以选择、修改答案、延期，或把该项交给 Codex。答复会写入[设定审核](设定审核.md)。
2. **Codex 统筹写作。** 从人物的日常和眼下的选择组织场景，让初读者能直接认出熟悉地方的反常。编辑复核行动依据、视角和连续性，配图从城市环境取景。正文按卷存放，章稿状态集中记在[正文索引](正文/README.md)。
3. **写完留下可接续的进度。** 人物状态、时间线和伏笔随定稿推进。每轮结束时，更新[创作进度](创作进度.md)，让下一次接着同一版设定和正文工作。

设定集 v1.0 是创作底稿。已通过的新增或修订设定以[设定审核](设定审核.md)为准，故事中已经发生的事件以定稿为准。原稿的叙事结构建议和案例作为创作素材，现行写法见[创作流程](创作室/工作流程.md)。
