# 第一卷策划

首卷从陈宁的一次普通下班写起。赶末班车、找站务、去有灯的药店，本来是走惯了的路上就能办成的事。读者跟着他和周棠，看见本该往上的楼梯通到了另一头，那家开着灯的药店走了几步还是够不着。两人要找的是能走的路、能应声的人，以及今晚回家的办法。[全书规划](全书规划.md)

## 第001章 序章

- **本章目标** 经由槐渡天桥的绕行交代异常事件如何进入城市日常。把视角收至陈宁，写他如何确认一单饭的去向，又如何遇到一则与眼前现场对不上的广播。
- **起始状态** 槐渡天桥已经封闭九天，附近居民借地铁站过街。陈宁正收拾电脑准备下班。
- **章末状态** 陈宁处理完门店的关店问题，带着两个红薯走到槐渡站 C 口楼梯底。卷帘门收起，有人从街上进来，广播两次说 C 口临时关闭。周棠约在闸机口等他，最近一条消息说末班车还有七分钟。

| 查单，陈宁 | 当晚，桥东写字楼 | 门店关店在即，取餐屏还亮着。陈宁比对取餐和出单记录，用测试店复现 | 陈宁和读者看到已取餐的订单补打小票后会重新出现在待取统计里 | 门店落闸，陈宁记下复现步骤再下楼 |
| 赶车，陈宁 | 随后，槐渡站 C 口 | 陈宁买完红薯去和周棠会合，在楼梯底停下来听广播 | 他刚从 C 口走下来，又看见有人进站，广播却反复说 C 口关闭。下楼时他在扶手上挂了一下袖口 | 广播响着，陈宁走向闸机找人 |

- **章末状态** 两人站在 B 口短梯顶端、铜条的站厅一侧。周棠拉住陈宁的袖子等广播停下。钥匙已交还周棠，两人各拿一袋红薯，陈宁左手掌根有一道小擦伤。

## 第003章 雨棚

- **本章目标** 周棠想上街找人，顺便给陈宁要张创可贴。两人到了雨棚下，药店看着近，走过去时始终还隔着三块砖。
- **起始状态** 两人在 B 口短梯顶等广播念完。周棠拉着陈宁的袖口，钥匙已收在她的外套兜里。两人各有一袋红薯，陈宁用纸角按住左掌根擦伤。
- **章末状态** 两人停在雨棚下通往药店的灰砖上，身后是楼梯口旁的铁盖。红垫子仍隔三块砖，刚走过的两处砖缝已在身后。

## 首个单元的后续策划

### 第006章起笔

- **起始状态** 两人在摊主抬起的红塑料布下避雨。陈宁用干纸巾按着左掌根，周棠拿着他的红薯，自己的红薯和钥匙仍在兜里。
- **先接摊主的话。** 陈宁按住伤口后，可以问摊主刚才有没有看见他下楼，接上那句「怎么又上来了」。摊主按亲眼所见回答，手上还在收摊。周棠手里拿着红薯，想的是两个人怎么回家。
- **让叫车的事往前走。** 从周棠先前提议坐同一辆车接下去。手机上的回应、摊主所见和两人的体感若有一处明显对不上，就写清那一处和人物随即做的事。章末可收在求助有了回应、两人选定去处，或一件回到日常后仍让人在意的小事。
- **设定依赖** 走出 C 口和摊主应声是已发生的事，是否成功出域待证。要写到确认归来，须能分别对应陈宁和周棠各自的入域时刻，保留离域时的身体状态。物品往返或跨时相遇一旦成为后续行动必需，再逐项提审。[设定审核](../设定审核.md) [双时间线](../资料库/双时间线.md)

### 第一卷接下来

首个单元可以在两人安顿下来以后收束。回家、处理擦伤、次日再经过槐渡一带，都可以承接这晚留下的变化。改报后 B 口实际通向哪里、药店与天桥是否有关，可以留作未知。后文若由新的遭遇、同伴的求助或生活里绕不开的事牵回这里，再选择需要弄清的局部事实。具体回访按已通过的入口规则处理。
