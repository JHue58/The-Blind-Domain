# 第一卷策划

首卷从陈宁的一次普通下班写起。第一次调查让他在熟悉的地铁站里核对亲眼所见与站内指示，进而为是否相信一条路线、是否回头作出选择。旧提案中的末班车和错向广播可以作为场景素材。[示例域闻档案](../盲域_世界观设定集_v1.0/10_示例域闻档案.md)

## 第001章 序章

- **本章目标** 经由槐渡天桥的绕行交代异常事件如何进入城市日常。把视角收至陈宁，写他如何确认一单饭的去向，又如何遇到一则与眼前现场对不上的广播。
- **起始状态** 槐渡天桥已经封闭九天，附近居民借地铁站过街。陈宁正收拾电脑准备下班。
- **章末状态** 陈宁处理完门店的关店问题，带着两个红薯走到槐渡站 C 口楼梯底。卷帘门收起，有人从街上进来，广播两次说 C 口临时关闭。周棠约在闸机口等他，最近一条消息说末班车还有七分钟。

### 审稿记录

- **当前稿** [第001章 序章](../正文/第一卷/第001章.md)，草稿 v0.1。
- **设定与连续性** 公众能看到异常事件的公开消息。天桥视频只提供画面，站内现场只提供陈宁此刻观察到的偏差。周棠先下楼，两人约在闸机口碰头。现实日期先用相对时间登记。
- **伏笔与接续** C 口扶手接缝的焊珠在让路动作中出现。第002章从楼梯底接起，两人在闸机口核对各走的入口，并在第一次试走 B 口时用这处接缝辨认位置。[线索与伏笔](../资料库/线索与伏笔.md)

## 第002章 另一头

- **本章目标** 陈宁和周棠从赶车转向找出口。陈宁认出进站时见过的扶手，周棠用钥匙和自己的位置帮他确认复走结果。
- **起始状态** 陈宁在 C 口楼梯底，拿着两袋红薯。C 口卷帘还收着，广播已两次说该口临时关闭。周棠在闸机边等他。
- **章末状态** 两人站在 B 口短梯顶端、铜条的站厅一侧。周棠拉住陈宁的袖子等广播停下。钥匙已交还周棠，两人各拿一袋红薯，陈宁左手掌根有一道小擦伤。

| --- | --- | --- | --- | --- |
| 会合，陈宁 | 紧接序章，槐渡站闸机外 | 闸机亮红叉，站务窗口无人应答。两人核对进站路线和广播，改走 B 口上街叫车 | 周棠说从 B 口进来时还在报车。陈宁看见 C 口开着时已在播关闭消息 | 赶车计划搁下。周棠知道药店一侧的地面路线 |
| 第一次走 B 口，陈宁 | 站厅另一端的短梯及 C 口楼梯 | 两人依指示上短梯，跨过铜条左拐。预期中的上行梯成了下行梯 | 陈宁从焊珠认出 C 口扶手。两人发现卷帘已落地，侧方是瓷砖墙 | 陈宁撑扶手时擦破掌根。两人从 C 口楼梯下到站厅 |
| 复走，陈宁 | B 口转角、C 口楼梯 | 周棠在焊珠下一阶放钥匙，退到楼梯底看住卷帘。陈宁再走 B 口 | 陈宁跨过铜条后认出白胶布裹柄的钥匙。周棠听见他从楼梯上叫她，目击卷帘在复走期间闭合 | 两人确认这次能从 B 口的转角再次抵达 C 口楼梯。陈宁带回钥匙 |
| 等待，陈宁 | B 口短梯顶端 | 两人回到转角，听见滴水。新一轮提示音响起时，周棠拉住陈宁 | 周棠记得进站时在转角听见药店雨棚漏水。两次试走都发生在广播念后半句时 | 两人留在铜条的站厅一侧，准备停播后一起试走 |

### 审稿记录

- **当前稿** [第002章 另一头](../正文/第一卷/第002章.md)，草稿 v0.1。
- **设定与连续性** 只登记目击顺序。C 口在序章末尾敞开，两人第一次从 B 口折返时卷帘已闭合，周棠只目击了复走期间的卷帘状态。钥匙放下、捡起、交还的经过均在陈宁视角内。分别保存陈宁的擦伤、周棠的证词与两人当前持有物。
- **伏笔与待验证** 焊珠从序章的生活细节变为识别 C 口的依据，钥匙支持复走结果。广播、滴水声与路线变化的关系有待对照。首次入域的锚点和现象归属留待后续取证。[线索与伏笔](../资料库/线索与伏笔.md)、[槐渡站调查底稿](../资料库/域区与域闻.md#槐渡站调查底稿)
- **接续位置** 第003章从广播尚在念、两人停在 B 口铜条前起笔。周棠知道常规路线，陈宁可以随她核对转角后的楼梯和墙面。

## 首个单元的后续策划

1. **对照路线。** 等广播停下，两人一起走过铜条。先找周棠记得的第二段上行梯、翘角的广告和药店雨棚，确定走到了哪里。[槐渡站调查底稿](../资料库/域区与域闻.md#槐渡站调查底稿)
2. **决定去留。** 根据对照结果决定停留、折返或撤离。若能走到街面，继续核对有没有恢复通常的街景和人员活动，记录两人各自看到的证据。
3. **归来与回访。** 写到归来时核对个人的现实时间锚点和身体状态。以后是否回访，由角色手上可复验的证据和现实牵挂决定。[设定审核](../设定审核.md)、[双时间线](../资料库/双时间线.md)
