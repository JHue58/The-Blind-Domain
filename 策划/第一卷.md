# 第一卷策划

首卷从陈宁的一次普通下班写起。赶末班车、找站务、去有灯的药店，本来是走惯了的路上就能办成的事。读者先跟着两个人经历这些小事变得难办，再看他们凭已经见到的东西决定往前还是回头。旧提案中的末班车和错向广播可以作为场景素材。[示例域闻档案](../盲域_世界观设定集_v1.0/10_示例域闻档案.md)

## 第001章 序章

- **本章目标** 经由槐渡天桥的绕行交代异常事件如何进入城市日常。把视角收至陈宁，写他如何确认一单饭的去向，又如何遇到一则与眼前现场对不上的广播。
- **起始状态** 槐渡天桥已经封闭九天，附近居民借地铁站过街。陈宁正收拾电脑准备下班。
- **章末状态** 陈宁处理完门店的关店问题，带着两个红薯走到槐渡站 C 口楼梯底。卷帘门收起，有人从街上进来，广播两次说 C 口临时关闭。周棠约在闸机口等他，最近一条消息说末班车还有七分钟。

## 首个单元的后续策划

1. **走到 C 口。** 从两人沿闸机并排前进接写。可从陈宁的手伤、纸袋还剩的温度或两人对末班车落空的反应切入。卷帘、扶手和广播写到足够让读者明白他们为何继续或停下。[槐渡站调查底稿](../资料库/域区与域闻.md#槐渡站调查底稿)
2. **决定去留。** 以眼前一处能改变去向的所见，支撑继续上楼、退回或另找路的选择。写到接近街面时，从人物实际能走到哪、能联系到谁来写。站里的播报与通路如何相连，可以随证据继续悬置。
3. **归来与回访。** 写到归来时核对个人的现实时间锚点和身体状态，并留出回到日常之后处理伤势和这段经历的篇幅。以后是否回访，由角色手上可复验的证据和现实牵挂决定。[设定审核](../设定审核.md) [双时间线](../资料库/双时间线.md)
