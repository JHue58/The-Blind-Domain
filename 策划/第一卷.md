# 第一卷策划

首卷从陈宁的一次普通下班写起。天桥封闭让行人改走地铁，陈宁和周棠在站里找不到回家的路。第二天两人听从彼此的约定，改走地面的红绿灯，却眼看着一个孩子困在斑马线上。第一次两人想尽快回家，第二次他们已经到了安全的地方，得决定要不要回头叫住那些还在往站里走的人。[全书规划](全书规划.md)

## 首个单元的后续策划

### 第009章 从 B 口截流

周棠先留在雨棚下叫住还没下楼的行人，许慧去找站务。陈宁用昨晚那把留在 C 口的钥匙说清是哪一段路走错了，许慧由此引出「域闻」，两人将这句话留在几个人的交谈里。站务核对现场并先挡住 B 口的新客流。用还在楼梯上的人能否应答、能否走回雨棚来推进，省去重复走一趟确认。

对街的 C 口仍可入站。陈宁联系附近店里的老何，请他在入口叫住还没下楼的人。站务接手 B 口后，陈宁和周棠从地面绕到 C 口。老何见已经有人走下去，便走到上段还看得见的转角招呼人折返。章末留在陈宁赶到门槛，听见楼梯上密集的脚步声。

### 第010章 撤人

许慧向私下联系的人问出一处已经复走过的槐渡站入口，对方能指出由那里走到 C 口转角附近时见过的地标。陈宁和她去核对入口和记录，周棠在地面留存老何最后被看见的位置与时间。第010章收在陈宁决定再进去。第011章写实际回访时，先在场景卡核对入口维护和通行证据、入域者的经历与各自锚点。若撤人结果需要写到未归者的现实状态，把相应情节交作者审核。[设定审核](../设定审核.md)
