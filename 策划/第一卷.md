# 第一卷策划

首卷从陈宁的一次普通下班写起。第一次调查让他在熟悉的地铁站里核对亲眼所见与站内指示，进而为是否相信一条路线、是否回头作出选择。旧提案中的末班车和错向广播可以作为场景素材。[示例域闻档案](../盲域_世界观设定集_v1.0/10_示例域闻档案.md)

## 第001章 序章

- **本章目标** 经由槐渡天桥的绕行交代异常事件如何进入城市日常。把视角收至陈宁，写他如何确认一单饭的去向，又如何遇到一则与眼前现场对不上的广播。
- **起始状态** 槐渡天桥已经封闭九天，附近居民借地铁站过街。陈宁正收拾电脑准备下班。
- **章末状态** 陈宁处理完门店的关店问题，带着两个红薯走到槐渡站 C 口楼梯底。卷帘门收起，有人从街上进来，广播两次说 C 口临时关闭。周棠约在闸机口等他，最近一条消息说末班车还有七分钟。

### 审稿记录

- **当前稿** [第001章 序章](../正文/第一卷/第001章.md)，草稿 v0.1。
- **设定与连续性** 公众能看到异常事件的公开消息。天桥视频只提供画面，站内现场只提供陈宁此刻观察到的偏差。周棠先下楼，两人约在闸机口碰头。现实日期先用相对时间登记。
- **伏笔与接续** C 口扶手接缝的焊珠在让路动作中出现，供后续核对站内位置用。第002章从楼梯底接起，可以先让陈宁核对周棠听到的广播、所走的入口和两人约好的碰头位置。[线索与伏笔](../资料库/线索与伏笔.md)

## 首个单元的后续策划

1. **核对现场。** 从普通的广播误播或临时调度着手，让角色先找到可重复核对的路线细节。首个域闻的触发、代价和局部解法随这段调查拟定，再登记到[域区与域闻](../资料库/域区与域闻.md)。
2. **用证据改变选择。** 等实物和路线的证据齐全，再安排停留、折返或撤离的选择。明确各人实际看到的事，保留相互核对的机会。
3. **归来与回访。** 写到归来时核对个人的现实时间锚点和身体状态。以后是否回访，由角色手上可复验的证据和现实牵挂决定。[设定审核](../设定审核.md)、[双时间线](../资料库/双时间线.md)
