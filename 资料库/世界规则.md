# 世界规则索引

写作时先查当前口径，再按剧情需要读原稿章节。[设定审核](../设定审核.md)记录作者后续通过的规则和适用范围。

## 起草时需要核对的原稿口径

- **档案评级。** 原稿给出「未知、无害、诡异、高危、极危、死亡」，同时提出危险评估与记录状态双字段。先根据剧情登记风险、证据和已知生还记录。正式档案的标签用法见[设定审核](../设定审核.md)。[域闻](../盲域_世界观设定集_v1.0/02_域闻.md)、[档案体系](../盲域_世界观设定集_v1.0/09_档案体系与调查规范.md)
- **从域内带出的物品。** 原稿同时提及物品影响现实，以及现实污染与域漏的来源差别。剧情中先记录带出及异常出现的证据，等原因验证后再为现象归类。[域闻，第 2.3 节](../盲域_世界观设定集_v1.0/02_域闻.md)、[现实污染与域漏](../盲域_世界观设定集_v1.0/07_现实污染与域漏.md)
- **组织与机关。** 异管局、拾遗者、灰市、归档会和灯塔是势力素材。选用时落实组织覆盖范围和情报渠道。机关在剧情中按它的来源、规则与作用记档。[组织与势力](../盲域_世界观设定集_v1.0/08_组织与势力.md)、[机关与试炼](../盲域_世界观设定集_v1.0/06_机关与试炼.md)

术语和称谓查[设定集术语表](../盲域_世界观设定集_v1.0/11_世界观术语表.md)。档案内的证词、假说和已验证规则按[域区与域闻](域区与域闻.md)登记。
