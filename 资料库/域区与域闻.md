## 记录规则

1. **作者设定。** 写清一个具体案件如何触发、影响谁、付出什么代价、什么时候失效。尚悬置的真实机制标为待定。
2. **调查记录。** 逐条注明谁目击、何时发生、哪章给出证据。将证词、初步推测和复验结果分栏。可回访入口记录通行条件、维护情况和最后一次验证时间。局部地图注明路线方向。
3. **版本变更。** 记录旧规则适用期、变化事件、新规则及其证据。人物可继续相信过期档案，正文中的异常结果按其发生时的实际规则处理。

## 槐渡站调查底稿

第002章草稿 v0.1 对应的首个单元方案。调查范围是闸机外站厅、B 口短梯的转角、C 口卷帘内侧的楼梯。[第002章 另一头](../正文/第一卷/第002章.md)

- **现场证据** 两趟都从闸机外沿 B 口箭头走，上六级，趁广播念后半句时跨过铜条左拐，接到 C 口的下行梯。首次靠扶手焊珠认位置，复走靠周棠留下的钥匙和她对卷帘的观察核对。B 口短梯附近在播报间歇两次传来滴水声。
- **局部触发草案** 在这段通道，播放 C 口关闭广播时，从站厅一侧越过铜条并转弯，会到 C 口楼梯上段。两次试走只覆盖了广播的后半句。提示音是否也算在触发窗口内，留待现场验证。
- **已见代价** 陈宁第一次踩空，抓扶手时擦伤左手掌根。两人原定赶末班车，闸机前受阻后改找地面出口。
- **出口试写方案** 假设停播时 B 口恢复第二段上行梯。两人可以用周棠进站看到的广告、药店灯箱和雨棚逐段核对，先确认能否到街面，再判断实际到了哪儿。
- **待取证** C 口卷帘的变化原因、滴水的来源、首次入域时点和异常的归属。天桥录像与站内折返之间的联系待查。[第001章 序章](../正文/第一卷/第001章.md)
