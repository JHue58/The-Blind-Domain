## 记录规则

1. **作者设定。** 写清一个具体案件如何触发、影响谁、付出什么代价、什么时候失效。尚悬置的真实机制标为待定。
2. **调查记录。** 逐条注明谁目击、何时发生、哪章给出证据。将证词、初步推测和复验结果分栏。可回访入口记录通行条件、维护情况和最后一次验证时间。局部地图注明路线方向。
3. **版本变更。** 记录旧规则适用期、变化事件、新规则及其证据。人物可继续相信过期档案，正文中的异常结果按其发生时的实际规则处理。

## 槐渡站调查底稿

依据第002至004章草稿 v0.4、第005至006章草稿 v0.3 和第007章草稿 v0.2。记录范围包括闸机外站厅、B 口短梯及上段、药店雨棚下的铺砖处、C 口楼梯，以及门外的红薯摊至公交站牌一段。时间核对接到两人分别到家以后。[正文索引](../正文/README.md)

- **铜条试走** 两趟都从站厅一侧沿 B 口路线走，在广播念后半句时跨过同一道铜条过弯，接到 C 口的下行梯。首次见到进站时的焊珠和 C 口牌。复走时陈宁在脚边见到周棠留下的钥匙，周棠说这段时间卷帘一直关着。第三趟在停播后过弯，两人到了带翘角广告的上行梯，广播再响时还能站在同一段楼梯上。
- **求助经过** 两人会合时先敲站务窗口，无人应答。第一次折返到 C 口后，周棠试过卷帘，也朝街上喊过话。两人退回站厅，周棠两次拨报警电话，均未接通。两人约定过弯就出声，陈宁才再走 B 口找上街的路。[第002章 另一头](../正文/第一卷/第002章.md)
- **雨棚声源** B 口短梯附近在播报间歇传来两声相连的滴水，陈宁觉得近在脚边。走到上行梯顶，两人亲眼看到棚沿的水先后滴在排水沟铁盖上。周棠截住后一滴时，铁盖只响一次。铁盖是眼前的声源，楼下听见的响声是否也来自它待证。
- **药店门距与折返** 从铁盖旁望向药店，离门还有三块砖。两人走过积水和烟头标记的两处砖缝后，陈宁再看时离门仍是三块砖，贴着红垫子的那块还是湿了一半。停在原地喊话未听见答复。陈宁用鞋尖拨翻烟头，两人再绕过积水缝，退回楼梯口的铁盖旁。
- **下行回站厅** 两人沿有卷角广告的楼梯向下，在转角前等 C 口关闭的播报结束。停播后转弯并跨过铜条，沿短梯回到闸机外。
- **播报内容变化** 两人在站厅听见下一轮提示音和女声。关闭对象从 C 口换成了 B 口，B 口箭头仍在原处。第005章两人在 C 口上段听见再次播报 B 口关闭。
- **C 口上行** 陈宁踏上第一级时看见卷帘正在升起。上楼途中他经过扶手焊珠，靠近门槛时看见原先压在门下的湿纸。卷帘在下一轮提示音之前已经收进门洞顶。两人在再次播报 B 口关闭的后半句跨过门槛，走到街边的摊灯下。摊主听到周棠喊话后转身，认出陈宁并递给他干纸巾。[第005章 摊灯](../正文/第一卷/第005章.md)
- **街面证词** 摊主说看见陈宁下楼时在扶手边扯袖子。他称自己等陈宁下去后开始系绳，结还没打完，两人就上来了。陈宁想起在药店前等应答的时间，又看到摊主当着自己的面很快把结拉紧。[第005章 摊灯](../正文/第一卷/第005章.md)
- **叫车和报平安** 周棠在摊边叫车，两人在公交站牌前核对车牌后同车离开。到家后，陈宁冲洗左掌根的擦伤，等到周棠来电。周棠说自己在门口找了半天钥匙，其实一直攥在手里。[第006章 双闪](../正文/第一卷/第006章.md)
- **局部通路假说** 从站厅一侧过铜条后的路线可能随播报时点变化。正向试走覆盖了念后半句及停播两种情形。回程只有一次停播通过的记录。提示音期间的通路和广播与路况之间的因果待验证。
- **到家后的时间核对** 周棠说在闸机跟前发了「还有七分钟」，聊天显示 22:53。陈宁从 C 口下楼前的付款记录显示 22:54。摊边叫车的下单时间为 22:55。三张截图保存在两人的聊天里。[第007章 回信](../正文/第一卷/第007章.md) [双时间线](双时间线.md#槐渡当晚的时间证据草稿)
- **已见代价** 陈宁第一次踩空，抓扶手时擦伤左手掌根。摊灯下能看见伤口，到家后他洗了手，贴了创可贴。两人原定赶末班车，闸机前受阻后改找地面出口，约好次日绕行。
- **随剧情取证** 两人的消息、付款和叫车记录为当晚的行动提供了可核对的时点。确切的入域锚点和归来时刻仍待证。改报后的 B 口通路、播报与卷帘的关系、各处现象的归属、天桥录像与站内及药店现象的联系，可以等到影响人物行动时再推进。次日另有[地面所见](#槐渡次日地面所见)。[第001章 序章](../正文/第一卷/第001章.md) [第一卷后续策划](../策划/第一卷.md#首个单元的后续策划)

## 槐渡次日地面所见

依据第008章草稿 v0.2 和第009章定稿 v0.3。[第008章 斑马线](../正文/第一卷/第008章.md) [第009章 转眼](../正文/第一卷/第009章.md)

- **可核对的斑马线地标** 陈宁和周棠跨过一道边上有缺口的白线，离对面路沿仍隔着三道。方才并排行走的路人已经先到了对面。小满折回去捡掉落的水壶，赶上信号灯变红。周棠带他跨过井盖，和陈宁一起退到护栏缺口。货车轧过白线上的水壶。[读者线索](../正文/档案室/huai-du-south-crosswalk.md)
- **复用的经验** 陈宁以昨晚能从药店门前踩到烟头、原路退回楼梯口为依据，叫周棠带孩子走来处。南边路口只观察到这一次回退经过，复现条件、影响对象和与天桥及药店现象的联系均待证。
- **许慧的证词** 她说曾在另一栋楼的楼梯上待到腿软，出来时送货人还扶着门。她是在另一名亲历者介绍的私下小群里听到「盲域」。她的经历地点、进出时点，以及与槐渡各处异常的关系待取证。[许慧](人物档案.md#许慧)
- **白天 B 口播报** 协管员引导行人借地铁站过街。到雨棚后，两人在敞开的 B 口听见「B 口临时关闭」。有人刚从站厅上来，也有人对拦路不满，继续下楼。提包人从街面越过转角后仍在讲电话。播报来源和入域的触发关系待证。
- **转角前后的见闻** 周棠追到转角里，陈宁听见提包人说完同一句话，随即见她跌回来。陈宁和许慧在同一段楼梯上目睹她带着左膝、右肘和左小臂的新伤，大口喘气，右手两次抓滑。她推拒靠近的人，盯着转角说「别碰我」。两名目击者等周棠讲述才能得知域内经过，路口与折返异常的归属或关联待证。[双时间线](双时间线.md#槐渡次日早上)

### 周棠的域内遭遇（定稿）

- **首次现身** 周棠拐过弯听不到电话的下半句，喊陈宁无人应答。她从卷角广告旁往上，看见平台边的人形和深色制服。应急灯只照到嘴和下巴。那人当面报 B 口关闭，开口前的吸气声与前一晚相同。[第010章 应声](../正文/第一卷/第010章.md)
- **收梯与间歇** 石阶自平台处依次缩入墙里，周棠跌伤左膝和右肘，退到弯内墙后。她从那里听完第二轮。停播后认出铁盖似的两声滴水，看见卷角广告上方露出一阶，从这里能够到平台边的扶手。[第011章 停播](../正文/第一卷/第011章.md)
- **攻击** 周棠握住扶手，被攥伤左小臂。第三轮开始，台阶再次收回，她悬在扶手上。对方掰开她的手指，造成右手无名指骨折。她挂在铁管上时，对方仍照常播报。[第012章 扶手](../正文/第一卷/第012章.md)
- **脱身** 握牢扶手并贴实右掌后，她首次发动熵力。其余手指离开铁管，右掌仍承重。她右脚、左膝落到平台后主动松手，带着手麻和伤势迈过转角，接回原锚点。[第012章 扶手](../正文/第一卷/第012章.md) [第009章定稿](../正文/第一卷/第009章.md)
- **取证范围** 作者已定，播报员在独处时才具备现身、改变环境和攻击的条件。周棠观察的是 B 口平台附近的一段梯级。首夜楼梯错接和早晨现实里的播报同它的关系待证。[关站决定](../设定审核.md#作者确认的播报员关站方式) [局部规则](../策划/第一卷.md#播报员的局部规则)
- **读者档案** 当面播报和目击示意图随第010章开放，第011章补收梯与停播，第012章补近身攻击。独处条件和现实播报来源继续按取证进度更新。[槐渡站 B 口播报员](../正文/档案室/huai-du-announcer.md)
