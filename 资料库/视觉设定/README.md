# 《盲域》视觉设定

配图前从这里取画风、人物参考和场景约束。首批图的提示词、章稿出处、参考版本和审图结果见[第一卷配图记录](第一卷.md)。制作及发布见[配图流程](../../创作室/配图流程.md)。

## 全书画风 v2

[阅读站封面](../../web/assets/cover.png)、[C 口梯底](../../正文/插图/发布/v1-c001-c-entrance-v1.jpg)和[楼梯口铁盖](../../正文/插图/发布/v1-c004-drain-cover-v1.jpg)供取景和材质参考。可借鉴后室的空间留白和 SCP 的现场记录感。地点、异常和可见线索以《盲域》当时的章稿为准。

> 现代中国城市的写实场景摄影，环境占主要画幅。保留真实的建筑比例、墙砖和金属磨损、被人用过的物件及充分可读的暗部。按现场天光、站灯、灯箱或摊灯安排明暗。可以用低饱和色和细颗粒，让不对劲藏在熟悉的环境里。人物有必要出现时，只留背影、难以辨认的远景或手脚等局部。

场景图可用约 3:2 的横构图，手机上应能看清关键环境。允许明亮、正常的白天场景，色温和明暗由地点决定。按正文核对文字、标识、反光和影子。玻璃、屏幕与水面反射同样避开人物正脸。档案示意图沿用实景风格，用图注说明取自哪个现场或所见片段。

## 地点参考

**槐渡站 C 口。** [第001章 C 口插图](../../正文/插图/发布/v1-c001-c-entrance-v1.jpg)保留瓷砖墙、金属扶手、向上的台阶和门洞顶的卷帘外观。序章回望时卷帘收起，看得到雨里的摊灯和一角红塑料布。第002章首次折返到这里时卷帘已落地。[第002章下行梯](../../正文/插图/发布/v1-c002-folded-stairs-v1.jpg)取陈宁再一次折返后的朝下视点。

[第005章 C 口插图](../../正文/插图/发布/v1-c005-c-entrance-v1.png)从第一级台阶仰望卷帘升起。帘片尚在门洞上部，门外近侧可看见同一盏摊灯和红塑料布。

**槐渡站闸机外。** [原闸机插图](../../正文/插图/发布/v1-c002-fare-gates-v1.jpg)供内部参考站厅的冷白灯、瓷砖和不锈钢。红叉对应会合时刻。B、C 两口的关系按正文当次观察处理，镜头范围依据所选段落。[槐渡站调查底稿](../域区与域闻.md#槐渡站调查底稿)

**槐渡站 B 口上行梯。** [原上行梯插图](../../正文/插图/发布/v1-c003-b-entrance-v1.jpg)供内部参考停播后过铜条、左转上行时的台阶及右墙卷角广告。梯顶的灯箱、雨棚和铁盖按后续段落的视点取景。[第003章 雨棚](../../正文/第一卷/第003章.md)

**槐渡站 B 口梯顶。** [第004章铁盖插图](../../正文/插图/发布/v1-c004-drain-cover-v1.jpg)可用作灰砖平台、梯口扶手与排水沟铁盖的局部参考。雨棚接缝在上方，药店灯箱的白光照到铁盖边，地面留有湿迹。[第004章 原路](../../正文/第一卷/第004章.md)

**雨棚下的药店。** [第003章药店门前](../../正文/插图/发布/v1-c003-pharmacy-door-v1.jpg)供玻璃门、灰砖、门下露出的暗红垫和店内一小片灯光参考。画面取门口局部，门距和去回两程的经过以章稿为准。[第003章 雨棚](../../正文/第一卷/第003章.md)
