# 《盲域》视觉设定

配图前从这里取画风、人物参考和场景约束。首批图的提示词、章稿出处、参考版本和审图结果见[第一卷配图记录](第一卷.md)。制作及发布见[配图流程](../../创作室/配图流程.md)。

## 全书画风 v1

[阅读站封面](../../web/assets/cover.png)是媒介与色调参考。生成时可带入封面或已审过的同类场景，按实际电灯、天光和夜色调整明度。画面的主信息在手机上也应看得清。

> 写实电影剧照，现代中国都市，35mm 胶片观感，细颗粒、低饱和青灰与煤黑，自然且克制的肤色和高光。灯具自然出现时使用暗琥珀色局部点光。保留暗部细节，用普通街道、墙砖、金属和潮湿表面的真实质感写出细小的反常。

场景插图可用约 3:2 的横构图，人物参考可用约 3:4 的近正面肖像。镜头内使用有出处的光源、道具和文字。遇到容易让读者误判的站牌、时钟或屏幕，先核对具体内容和出现时点，再决定是否入镜。

## 人物参考

首批脸型、发型、衣着色板由主编按开篇日常做了绘设，供后续插画保持识别度。人物身份、年龄和剧情事实按作者决定与章稿取用。将对应参考图文件带入每次生图，再逐人比对输出中的脸与体态。同一晚的情节沿用衣着和持物，后续换装按文本中的时点登记。改动固定参考前先检查此前的公开图和涉及外貌的剧情。

## 地点参考

**槐渡站 C 口。** [第001章 C 口插图](../../正文/插图/发布/v1-c001-c-entrance-v1.jpg)保留瓷砖墙、金属扶手、向上的台阶和门洞顶的卷帘外观。序章回望时卷帘收起，看得到雨里的摊灯和一角红塑料布。第002章首次折返到这里时卷帘已落地，重画时按当时状态制作。

**槐渡站闸机外。** [第002章闸机插图](../../正文/插图/发布/v1-c002-fare-gates-v1.jpg)供站厅冷白灯、瓷砖和不锈钢的材质参考。红叉对应会合时刻。B、C 两口的关系按正文当次观察处理，通路成因、滴水来源和未走到的路段暂时留在画外。[槐渡站调查底稿](../域区与域闻.md#槐渡站调查底稿)

**槐渡站 B 口上行梯。** [第003章上行梯插图](../../正文/插图/发布/v1-c003-b-entrance-v1.jpg)记录停播后过铜条、左转上行时可见的台阶及右墙卷角广告。梯顶的灯箱、雨棚和铁盖按后续段落的视点取景。[第003章 雨棚](../../正文/第一卷/第003章.md)

**槐渡站 B 口梯顶。** [第004章铁盖插图](../../正文/插图/发布/v1-c004-drain-cover-v1.jpg)可用作灰砖平台、梯口扶手与排水沟铁盖的局部参考。雨棚接缝在上方，药店灯箱的白光照到铁盖边，地面留有湿迹。[第004章 原路](../../正文/第一卷/第004章.md)
