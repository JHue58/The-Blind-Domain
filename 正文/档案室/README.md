# 《盲域》档案室

这里的 Markdown 供阅读站直接读取。每次新增或修订章稿，核对涉及的术语、人物、域区、域闻、能力与线索。有新条目时建档，有新证据时更新对应文件。剧情条目注明读者可查看的章节和正文出处。

读者看到的是《盲域》世界内未署名的调查档案。以地点、异常或被记录者为主语，先说明是什么、在哪里、现场观察到什么。把证词和现场经过记入附录，章号用在出处和公开范围。涉及推断时，写明它依赖哪项观察和还有什么待核实。[作者确认](../../设定审核.md#作者确认的档案室方向)

- **术语** 先给当前公开的定义，再写范围、判断依据或个案。口径见[世界规则索引](../../资料库/世界规则.md)和[设定审核](../../设定审核.md)。
- **人物** 先登记可公开的身份，再记与此人相关的证词、材料、接触或复访。补记注明出处。
- **域区和域闻** 域区先写环境和出入记录，域闻先写可辨表现和已见风险。域体按实体型域闻登记。归属或成因待确认时，先记在「线索」。
- **能力** 随出场记录使用者、所见效果和代价。正式称呼、发动条件与边界随正文明确的时点公开。

## 新建条目

每份档案在本目录存成一个 Markdown 文件。文件名使用小写字母、数字和短横线，例如 `entry-exit.md`。文件名决定阅读站的条目地址。

```markdown
---
title: 浴室墙上的池水
category: phenomenon
summary: 社区浴室的池水附于瓷砖墙面，池底的放水口外露。
after: v1-c015
facts:
  - v1-c015 | 记录状态 | 部分记录
  - v1-c015 | 证据来源 | 一名目击者
related:
  - v1-c015 | community-bath-zone
---

<!-- after: v1-c015 -->
## 描述

池水附在湿区尽端的瓷砖墙上。一只粉红色塑料盆浮在水面。

**出处** [第015章 浮盆](#/read/v1-c015)
<!-- /after -->

<!-- after: v1-c016 -->
## 附录｜池边受阻

门槛露出后，水流仍扫过池边。水流推倒长凳，将目击者抵在池壁上。

**出处** [第016章 送巾窗](#/read/v1-c016)
<!-- /after -->
```

- `title`、`category` 和 `summary` 为必填项，各写一行。类别用 `term`（术语）、`character`（人物）、`zone`（域区）、`phenomenon`（域闻）、`ability`（能力）、`clue`（线索）或 `other`（其他）。
- 文件头的 `after` 控制标题、类别、编号及初始摘要何时公开，这些字段填写首次公开时的内容。`opening` 表示从开篇可查，`v1-c002` 表示读完对应章后可查，`spoiler` 表示读者确认剧透后可查。已有档案编号用 `code` 填写。
- 新摘要在 `summaries` 按公开顺序追加，每行用 `- 公开章节 | 摘要`。目录与正文悬浮采用最后一条已公开的摘要。保留 `summary` 为初次公开时的简介。
- 标题公开后会成为正文词条。`terms` 可补充别名或术语，每行用 `- 词条 | 释义 | 小标题 | 公开章节`。小标题可留空，同一词只登记一次。新身份或称呼可在揭晓后作为别名出现。
- 正文新增记录放在 `<!-- after: 公开章节 -->` 与 `<!-- /after -->` 之间。正文出处写成 `**出处** [第001章 序章](#/read/v1-c001)`。线索跨章时，按该段信息完整揭示的章节解锁，出处保留各章的证据链接。
- 二级标题 `## 附录｜标题` 会折叠其后的证词、复查材料或观察细节，直到下一处同级标题或本段记录结束。影响行动的主要观察留在条目正文。
- 可用 `facts` 登记档案页首的要点，每行用 `- 公开章节 | 字段名 | 内容`。同一字段有变化时按公开顺序追加，页首取最后可见值，详情保留带章节出处的旧观察及后续修订。
- 可用 `related` 登记关联档案，每行用 `- 公开章节 | 条目文件主名`。关联双方都已开放时显示链接。两起异常是否同源仍待查时，在正文记录中写明已知联系和证据限度。
- 缺少公开章节的条目、别名和正文块可在确认剧透后查看。仍待正文揭示的设定可用 `spoiler`，写到揭示处再登记对应章节。

保存后，打开的阅读站会自动更新目录和正在查看的内容。已公开的术语也会出现在设定集。调查底稿和后续章纲分别维护在[资料库](../../资料库)和[策划](../../策划)。

## 调查档案字段

格式沿用[档案体系与调查规范](../../盲域_世界观设定集_v1.0/09_档案体系与调查规范.md)与[三类创作模板](../../盲域_世界观设定集_v1.0/12_创作准则与待确认事项.md#5-新增域闻的创作模板)。按现有证据填字段，随章节补齐。

| 类别 | 页首可用字段 | 历次记录可补入的内容 |
| --- | --- | --- |
| 域闻 | 首次目击、主要类型、记录状态、证据等级、已见风险 | 触发与表现、证据出处和重复次数、规避和生还记录、例外与仍待核实的推测 |
| 域区 | 已见范围、入口、出口、回程记录 | 通行条件、地点变化、待查边界和相连地点 |
| 能力 | 使用者、当次作用对象、所见效果、使用后、持续时间 | 首次使用经过、发动条件、作用边界和与异常的交互 |
| 线索 | 首次记录、可辨特征、现场对照、待核实 | 证词、场景或物证，后续复查与未解关联 |

新证据改变原先判断时，另加一段带章号的记录，交代原判断的适用范围、失效经过和依据。采用第 09 篇的证据等级时，注明是哪一次或哪几次记录支持它。正式编号和危险评级按作者已确认的口径登记。现行样式见[播报员](huai-du-announcer.md)、[槐渡站异常路段](huai-du-station-zone.md)和[周棠的抓握](zhou-tang-grip.md)。

## 档案配图

具体的域闻、域区、域体及已经单独建档的异常线索，每个条目首次公开时至少有一张能指向该处场景、该项现象或本体的已审图。纯术语条目按上面的释义格式维护，人物和能力条目可按出场需要选图。

- 把条目文件主名和图片关联公开章号写入[插图索引](../插图/索引.json)的 `archives`。用于首次公开的那张图，来源段落在该公开章或此前的章稿，并在 `anchor` 登记。槐渡站 C 口广播以第001章看得见的开放入口作配图，与条目同章解锁。
- 声音、传闻或外形不明的现象用已经写到的环境、物件或痕迹作示意，图注写明来源和性质。只有正文出现过的证物才可用证物示意图。图片和正文条目按相同的读者所知范围审核。
- 查档案的首次可见状态，确认对应图能随条目打开。需要补图的新异常记录可先写入[调查底稿](../../资料库/域区与域闻.md)，等图片通过审核后同轮公开。[配图流程](../../创作室/配图流程.md)
