# 《盲域》档案室

这里的 Markdown 供阅读站直接读取。每次新增或修订章稿，核对涉及的术语、人物、域区、域闻、能力与线索。有新条目时建档，有新证据时更新对应文件。剧情条目标出正文出处。

- **术语** 采用[世界规则索引](../../资料库/世界规则.md)和[设定审核](../../设定审核.md)中的当前口径。
- **人物** 记录章稿中已经交代的身份、关系和行动。发生变化时补上对应章节。
- **域区和域闻** 记录读者已看到的范围、现象和证据。归属或成因待确认时，先记在「线索」。
- **能力** 随出场记录使用者、所见效果、已知条件和代价。

## 新建条目

每份档案在本目录存成一个 Markdown 文件。文件名使用小写字母、数字和短横线，例如 `entry-exit.md`。文件名决定阅读站的条目地址。

```markdown
---
title: 入域与出域
category: term
summary: 现实时间在入域时暂停。成功归来的人接回各自的入域时刻。
terms:
  - 时间锚点 | 入域时的现实时间位置。 | 出域与时间锚点
---

## 出域与时间锚点

成功出域时，每个人回到自己进入盲域的时刻。
```

- `title`、`category` 和 `summary` 为必填项，各写一行。类别用 `term`（术语）、`character`（人物）、`zone`（域区）、`phenomenon`（域闻）、`ability`（能力）、`clue`（线索）或 `other`（其他）。
- 已有档案编号时，用 `code` 填写，站内可按编号搜索。
- 标题自动作为可检索、可在正文中点开的词条。`terms` 可补充别名或相关术语，每行写一个词及其释义。第三项可填本站档案正文里的小标题。同一词只登记一次。
- 正文出处可写成 `[第001章 序章](#/read/v1-c001)`。章号在地址里至少用三位数字。

保存后，打开的阅读站会自动更新目录和正在查看的内容。术语也会同步出现在设定集。调查底稿和后续章纲分别维护在[资料库](../../资料库)和[策划](../../策划)。
