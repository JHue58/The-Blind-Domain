# 第014章 通行

下午，陈宁跟同事补完早会上的事，才看到周棠发了两条消息。她说她已经到药店了，等他过来。隔了几分钟，她又发来一条。

「你先去问。我在雨棚外头。」

陈宁到雨棚下时，她正用左手往包里塞一张折好的单子。单子有一角卡在拉链里。他抬了抬手，周棠把包转了个方向，用胳膊夹住，把那张纸收了进去。

「许慧给我找了个袋子，片子也装好了。」她把挎包挪到左边，给楼梯上来的人让了让。

药店门外的红垫子晒得翘起来一角。许慧出来把它踢平，对陈宁说，「你走上来的时候在楼梯上喊一声。我们听听。」

陈宁从 B 口下楼。到了转角，他放慢了脚步。下面有人扶着栏杆往上来，拎了盒蛋糕。他侧身让了让，隔着盒盖上那片透明塑料看见一颗歪了的草莓。再往下走，是闸机和亮着灯的站务窗口。

窗口前的人走开以后，陈宁问，早上路口让人借地铁过街那会儿，B 口是不是报过临时关闭。

「你是说关过口，还是听见广播了？」

「广播说关了。楼梯上还有人。」

值班的人把一本蓝皮的本子从手边挪过来，翻了两页。「我下午接的班。要是封过口，交接的时候得记一笔。上午这一栏是空的。」

「广播呢？」

「这本上只记出入口的事。」对方抽出一张便签，「你大概几点听见的？我留给早班的人看一眼。」

陈宁报了个大概，说是南边路口停了一辆货车之后。对方在纸上写了个时间段，又问他是楼上听见的还是楼下听见的。陈宁指了指 B 口，说他们站在药店的雨棚下，声音从楼梯底传上来。

他离开窗口，走到那道铜条前。提示音刚好在头顶响起来。他停了一下，听见女声说请照看好随行儿童。一个女人牵着孩子从他身边过去，刚拐弯就说，「慢点，鞋带又开了。」

陈宁踩过铜条。女人蹲在上行梯上系鞋带。他从旁边走过去，看见了墙上卷着角的药店广告。再上几级，有人把自行车从雨棚前推过，一只脚已经踩上了踏板。

陈宁站在原地喊了声周棠。

「听见了。」周棠的声音从街上下来，「你走上来吧。」

许慧已请同事先看着店，在楼梯口等他。周棠听他说完窗口的答复，低头看了一会儿自己的鞋。

「我想走到广告那儿看看。你在前头。」她说完又看向许慧，「等看不见我了，喊我一声行吗？」

陈宁走在下面，和周棠隔着两级台阶。她用左手扶着栏杆，到了快拐弯的地方，把夹着板的右手往胸前收了收。广告还在。她停下来，用左手指背碰了碰卷起的纸角。那张纸弹了回去。

她拐过弯。

「周棠。」许慧在上头喊。

「听得见。」她站在转角下面，望着平台。「你也下来吧。」

许慧走过来时，周棠已经自己下了一级。站厅里有人拖着小行李箱，轮子碰到地砖接缝，一路响到了闸机边。那声音在楼梯上也听得清楚。三人跟着走到了站厅。

他们从 C 口上到街面。原来摆摊的地方空着。三人站了一会儿，又从那里往下走了一趟。陈宁经过那颗焊珠时，把袖口往腕上提了提。到了站厅，许慧和周棠先过铜条，陈宁等下一遍广播念完再走。等他上到雨棚，两人已经到了药店门口。周棠用脚尖踩了踩垫子。正要出门的店员给她让开了，说小心门槛。

「行了。」周棠转过身，「今天走到这儿吧。」

许慧拿手机给群里留了条消息，写着下午去过 B 口和 C 口，两个口都走通了。周棠等她发完，让她把站务说的也补上。许慧想了想，又打了一行。

「交接本上没记关口。报没报，等早班的人回话。」

出了雨棚，许慧在路边站住了。

「你看桥底下。」

卖红薯的把炉子推回了桥下。挡在桥梯前的铁板已经拆了，原来贴通告的地方露出一截栏杆。对面下来一排放学的学生，有人在桥中间停下，把校服扎在腰上，后头的人就从他身边挤过去。

三人走到桥脚。摊主正拿抹布擦炉盖，旁边是那块写了绕行箭头的纸板。他把纸板翻过来，垫在一只装零钱的盒子底下。陈宁买了两个红薯。周棠等他接了袋子，说过了桥再给她，她得空出手来扶栏杆。

许慧陪他们走上去。桥面上风大，周棠在往下走之前停了一下，把松掉的包带往肩窝推了推。一个学生追着同伴跑下去，鞋底在梯面上拍出几声脆响。

陈宁想起录像里那人脚下总剩三级。他低头也数了三声。踩过最后一级时，两只纸袋在腿边碰了一下。他已经站在人行道上了。

周棠从他身后下来，朝他伸出左手。

「给我小的那个。」
