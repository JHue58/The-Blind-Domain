# 第002章 另一头

收伞的人往站厅去了。伞尖在地砖上敲了两下，转过墙角，声音就听不见了。陈宁跟过去，想找站里的人问问广播的事。

周棠在闸机边上，一只手虚拢着手机，给屏幕挡顶上的光。她把乘车码往扫描窗上贴了贴，听了一会儿，又挪到旁边那台。陈宁走近了她才抬头。

「你来试试。刚才这一排还亮绿的。」

现在亮着一排红叉。陈宁调出乘车码试了一次，机器一点声音也没有。他收起手机，把多套了一层纸的那袋红薯递给她。

「拿底下，刚出炉的。」

周棠接过去，两只手托着。站厅里的广播又响起来，和楼梯底下听见的是同一句。

「你进来的时候也在播这个？」陈宁问。

「那会儿还在报车。」她看他一眼，「你从C口下来的？」

「卷帘收着。后头还有人下来。」

「我走的B口。药店那边有棚，一路能躲雨。」

站务窗口亮着灯。玻璃后面搁了只饭盒，一双筷子还横在盒盖上。陈宁弯下腰，朝传声孔问了句还有没有车。等了一会儿，周棠拿指节在玻璃上轻轻敲了两下。没人应。

「上去叫车吧。」她说，「药店门口有地方等。」

B口的箭头挂在闸机另一头。两人走上六级短梯，到了拐弯的地方。地上嵌着一道铜条，边上积着鞋底带进来的黑泥。

「过了弯还有一截。」周棠走在前面，「上去就看得见灯箱了。」

女声又念到「请从其他出入口进出」。周棠跨过铜条往左拐，陈宁紧跟上去。他以为脚下还有一级往上的台阶，一脚踩了个空。

周棠扯住他的胳膊。两个人挤在同一级台阶上，陈宁的左手撑住扶手，掌根在一处突起上刮了一下。他低下头，看见接缝上鼓着一颗小小的焊珠。

他翻过手腕。袖口那根松脱的线还挑着。

「我下来的时候，在这儿挂了一下。」

周棠转过身。楼梯上头的卷帘门已经落了地，门框边钉着一块蓝底的C口牌。

他们明明走的是B口。陈宁侧过身去找刚才的转角，那里只有一面瓷砖墙。

周棠贴着墙往上走了几步，俯身朝卷帘底下看。陈宁等着听见街上的雨声，听见的是她手里的纸袋响了一下。

「你手上有血。」她回过头说。

陈宁张开手，掌根破了一小道。周棠从红薯袋的外层撕下个干净的角，递给他按着。两个人顺着楼梯往下走，又回到了闸机外。那排红叉还亮着。

周棠望向闸机那头。「我从B口下来的时候，墙上还有张药店广告。底下翘着个角，我袖子还蹭到了。」

「我再走一趟B口。你在这儿帮我看着卷帘。」陈宁说，「过弯我就喊你。」

周棠把红薯塞进外套兜里，腾出手来。「看见路了也喊我一声。」

她从另一边兜里摸出那串钥匙，走回去，搁在焊珠下边那一级。有一把钥匙的柄上缠着白胶布，底下垫着别的钥匙，翘起来一点。

「要是还走到这儿，就把它给我拿下来。」

等周棠退回楼梯底，陈宁又走向B口。那边的转角传来两声滴水，紧接着是广播的提示音。

女声念到「请从其他出入口进出」时，他跨过铜条，一拐弯就停住了。

脚下又是往下的台阶。那串钥匙就在他脚边，缠着白胶布的那一把还翘着。周棠刚才明明把它留在了站厅另一头的C口楼梯上。

他喊了声周棠。楼梯底下立刻有人应他，近得用不着喊这么大的声。周棠仰着脸，一只手还搭在最下面的扶手上。广播的尾音落了。

「门开过吗？」

她摇摇头。「我一直看着。你是从上面叫我的。」

陈宁回头看了眼卷帘门。门底压着一小片湿纸，纸角紧贴在地上。他把钥匙捡起来，一级一级走回周棠身边。她摊开手，等钥匙落进去才收拢手指。

「刚才广播响以前，B口有滴水声。」陈宁说。

周棠把钥匙揣进兜里，往B口走。陈宁跟着她上了短梯。到最上一级，那两声滴水又响了，近了许多。

「我下来的时候听见过。」周棠说，「药店的棚子往下漏，走过弯还能听见。」

陈宁刚要迈过铜条，提示音又响了。周棠拉住他的袖子。铜条那头很快只听得见那个女声了。

「等这一遍念完。」她说。

陈宁把抬起的那只脚收回来，和她站在同一级台阶上。
